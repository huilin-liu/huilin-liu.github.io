## About me

I have nearly two years of experience as a technical writer at a medical-device company. My work included writing and maintaining user manuals, release notes, datasheets, and service manuals in both Chinese and English, as well as reviewing bilingual software UI strings.

I am moving into API and developer documentation. I am learning API design, API documentation, programming languages, docs-as-code workflows, documentation tools, and version control. The work on this site shows what I built through that learning: a redesigned Kimi API Quickstart and an OpenAPI 3.1.1 specification for an API that did not provide an official OAS.
