# Kimi API documentation redesign

An independent documentation redesign focused on helping developers make their first successful Kimi API request with less friction.

This portfolio project audits and restructures the official quickstart around one outcome: send a request to the Kimi Chat Completions API and confirm that it returned a response.

## Explore the project

- [Read the redesigned Quickstart](quickstart.md) to follow the cURL, Python, or Node.js workflow.
- [Read the case study](case-study.md) to learn about the audit findings, design decisions, validation, and AI-assisted review process.

## Project scope

The project focuses on the Kimi API Quickstart. It does not redesign the API or attempt to document every supported feature.

Kimi's official documentation remains the source of truth for technical facts. This is an independent documentation exercise and is not affiliated with Moonshot AI.
